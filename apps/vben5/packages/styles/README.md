# @vben/styles

Dùng chung cho nhiều `app` các file kiểu, kế thừa mọi khả năng của `@vben-core/design`. Nếu nghiệp vụ có file kiểu dùng chung thì có thể đặt ở đây.

## Cách dùng

### Thêm dependency

```bash
# Vào thư mục ứng dụng đích, ví dụ apps/xxxx-app
# cd apps/xxxx-app
pnpm add @vben/styles
```

### Sử dụng

```ts
import '@vben/styles';
```
